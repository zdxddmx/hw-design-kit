# 数据采集主控板 · 硬件测试方案

## 一、测试范围

- 电源与上电时序

## 二、上电检查表

| # | 步骤 | 内容 | 预期 | 实测 | 结论 |
|---|---|---|---|---|---|
| 1 | 上电前目视检查 | 确认无连锡/虚焊、极性器件方向、保险丝与跳线 | | | ☐ |
| 2 | 限流上电 | 电源限流至额定 1.2 倍，观测输入电流是否异常 | | | ☐ |
| 3 | 静态电流测量 | 空载测各路静态电流，与设计值比对 | | | ☐ |
| 4 | 电源轨电压 | 逐路测量输出电压与纹波（示波器 AC 耦合，20 MHz 带宽限制） | | | ☐ |
| 5 | 复位与时钟 | 示波器确认复位时序与晶振起振（频率与幅值） | | | ☐ |
| 6 | 烧录与识别 | 烧录固件后确认芯片被识别、串口有启动打印 | | | ☐ |
| 7 | 接口回环 | 逐项做接口回环/读写验证（UART 回显、I2C 扫描、SPI 读写、CAN 帧、USB 枚举） | | | ☐ |
| 8 | 功能联调 | 按测试用例逐项验证功能，记录实际结果与预期是否一致 | | | ☐ |
| 9 | 温升与长稳 | 满载运行至热平衡，记录关键器件温度；持续运行观察是否异常复位 | | | ☐ |

## 三、接口测试项

| 接口 | 测试内容 | 仪器 | 预期 | 实测 | 结论 |
|---|---|---|---|---|---|
| I2C | 扫描地址、读写寄存器、观察上升时间与总线电容 | 示波器 / 逻辑分析仪 | | | ☐ |
| UART | 回环测试、误码统计、观察空闲电平与波特率误差 | 示波器 / 逻辑分析仪 | | | ☐ |
| CAN | 帧收发、总线仲裁、示波器看差分电平与位定时 | 示波器 / 逻辑分析仪 | | | ☐ |
| USB | 枚举、设备描述符、批量传输速率与稳定性 | 示波器 / 逻辑分析仪 | | | ☐ |

## 四、记录要求

- 每个测试项都要记录**原始数据**（波形截图、实测值、时间），不允许只写"正常"
- 与预期不一致的项必须单独列出并跟踪到关闭
- 结论要能追溯到**测量条件**（温度、负载、电源电压、仪器型号与档位）
